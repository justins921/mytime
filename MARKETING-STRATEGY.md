## 11. Onboarding CRO (onboarding-cro)

### Activation Event
**Definition:** User generates their first weekly schedule with at least 2 clients.

### Onboarding Checklist (in-app, post-signup)
1. Add your first client (quick win, 30 seconds)
2. Add a second client
3. Set your availability
4. Generate your first week ← activation event
5. Start the timer for your current block
6. Connect Slack or Gmail (optional, power users)

### Empty States
- Schedule page: "Hit Generate to see your perfect week" + Generate button
- Timer page: "Start tracking — your time is money" + Start button
- Messages: "Connect Slack to see all your messages here" + Connect button

### Stalled User Recovery
- 24h no activity: Email "Need help getting started?"
- 72h no activity: Email with video walkthrough
- 7d no activity: Personal email from founder

## 12. Analytics Tracking (analytics-tracking)

### Key Events (implemented in code)

| Event | Properties | Trigger |
|-------|-----------|---------|
| `cta_clicked` | button_text, location | Any CTA button click |
| `waitlist_joined` | method | Waitlist form submit |
| `calculator_used` | client_count | Calculator results shown |
| `demo_watched` | tab | Demo tab viewed |
| `pricing_viewed` | plan | Pricing section scroll |
| `faq_opened` | question | FAQ item expanded |
| `referral_clicked` | — | Referral card interaction |

### Setup Required
1. Create GA4 property at analytics.google.com
2. Get Measurement ID (G-XXXXXXXXXX)
3. Add to `.env`: `NEXT_PUBLIC_GA_MEASUREMENT_ID=G-XXXXXXXXXX`
4. Events will start tracking automatically

### Key Dashboards to Create
- **Conversion funnel:** Page view → CTA click → Waitlist join
- **Feature engagement:** Which demo tabs get watched
- **Calculator usage:** Completion rate, avg client count
- **Traffic sources:** Where signups come from
