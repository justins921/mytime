# Work OS - Client Workday Manager

A web app that automatically generates your weekly work schedule based on availability, clients, targets, and rules. Includes a task manager and time tracker. Deployable on Vercel, responsive across phone, tablet, and desktop.

## Stack

- **Next.js 16** (App Router) + TypeScript
- **Tailwind CSS v4** + shadcn/ui components
- **Prisma ORM** (SQLite for dev, Neon Postgres for production)
- **Auth.js / NextAuth v5** with Email Magic Link (Resend)
- **Vercel** deployment

## Local Development Setup

### Prerequisites

- Node.js 18+
- npm

### 1. Install dependencies

```bash
npm install
```

### 2. Configure environment

Copy the example env file and fill in your values:

```bash
cp .env.example .env
```

For local development, the defaults work:

```
DATABASE_URL="file:./dev.db"
AUTH_SECRET="dev-secret-change-in-production-abc123"
ALLOWED_EMAIL="you@example.com"
RESEND_API_KEY=""
NEXTAUTH_URL="http://localhost:3000"
```

**Note:** Without a Resend API key, the magic link email won't actually send. For local dev, check the terminal output for the magic link URL, or temporarily bypass auth by commenting out the middleware.

### 3. Set up the database

```bash
npx prisma db push      # Create tables
npm run db:seed          # Seed default data
```

### 4. Run the dev server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production Setup (Vercel + Neon Postgres)

### 1. Create a Neon Postgres database

1. Sign up at [neon.tech](https://neon.tech)
2. Create a new project and database
3. Copy the connection string

### 2. Update Prisma schema for Postgres

Change `prisma/schema.prisma` datasource provider:

```prisma
datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}
```

### 3. Set up Resend for emails

1. Sign up at [resend.com](https://resend.com)
2. Create an API key
3. Verify your domain (or use `resend.dev` for testing)

### 4. Deploy to Vercel

1. Push your code to GitHub
2. Import the repository in Vercel
3. Add environment variables:

| Variable | Value |
|---|---|
| `DATABASE_URL` | Your Neon Postgres connection string |
| `AUTH_SECRET` | Generate with `openssl rand -base64 32` |
| `ALLOWED_EMAIL` | Your email address (only this email can log in) |
| `RESEND_API_KEY` | Your Resend API key |

4. Set the build command to: `npx prisma db push && npm run build`
5. Deploy

### 5. Seed production database

After first deploy, run against production:

```bash
DATABASE_URL="your-neon-connection-string" npx prisma db push
DATABASE_URL="your-neon-connection-string" npx tsx prisma/seed.ts
```

## Architecture

### Schedule Generator

The schedule generator (`src/lib/scheduler/engine.ts`) is rule-based:

**Inputs:**
- Weekly availability windows per weekday (default 9:00-3:30)
- Fixed breaks (e.g., 10:15-10:45 school pickup - locked)
- Lunch reserve (12:45-1:15 - editable)
- Optional night work windows per day
- Client configurations with targets, styles, and priorities

**Algorithm:**
1. For each weekday, compute available time slots (subtract breaks)
2. Place bookend support sweeps (start and end of day) for Support-style clients
3. Reserve admin/wrap time near end of day
4. Allocate deep work blocks based on priority weights and weekly targets
5. Ensure daily-touch clients get at least one block per day
6. Add night work blocks if enabled for that day
7. Sort all blocks chronologically

**Controls:**
- **Keep locked** - regeneration preserves user-locked blocks
- **Keep manual** - regeneration preserves manually-created blocks
- **From now** - only schedule remaining time today, accounting for current time

**UC30 Rule:** UC30 project time under Chandler never expands automatically. Set explicit allocation in Settings > UC30 Weekly Hours. If UC30 pushes Chandler over target, warnings appear.

### Locking Blocks

Click the lock icon on any schedule block to lock it. Locked blocks survive regeneration. Manually created blocks (not generated) also survive if "Keep manual" is enabled.

### Time Tracking

- Start/stop timer tied to client, project, and task
- Warns if switching to a different client than the current schedule block
- Automatic daily/weekly/monthly aggregation in Reports
- CSV export

## Environment Variables

| Variable | Required | Description |
|---|---|---|
| `DATABASE_URL` | Yes | SQLite path for dev, Postgres URL for production |
| `AUTH_SECRET` | Yes | Secret for Auth.js session encryption |
| `ALLOWED_EMAIL` | Yes | The single email allowed to log in |
| `RESEND_API_KEY` | Yes (prod) | Resend API key for sending magic link emails |
| `NEXTAUTH_URL` | No | App URL (auto-detected on Vercel) |
